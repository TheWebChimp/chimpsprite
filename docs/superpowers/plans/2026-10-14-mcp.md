# MCP server — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Spec: `docs/superpowers/specs/2026-10-14-mcp-design.md`

1. **Base compartida**: mover `cs-ui/src/files.rs` a `cs-io::files` (la UI lo importa de ahí);
   `DocCommand::SetSprite { id, sprite }` con su inverso y caso en el proptest de undo.
2. **cs-agent: sesión y direccionamiento**: `Session` (documentos, ids `d1…`, historial, ruta,
   `--root`), `AgentError`, `Reply`, resolución de artboard/capa/frame/color, `execute` atómico,
   undo/redo, `apply_commands`. Tests.
3. **Documentos y estructura**: new/open/save/close/list/describe; artboards, capas, frames, tags,
   cels. Tests de efecto + undo + errores.
4. **Dibujo y color**: draw_pixels/line/rect/ellipse/fill/erase con brush y clip; set_palette,
   recolor por scope, quantize (median cut, a indexado vía `SetSprite`). Tests.
5. **Transformaciones e inbetween**: flip, rotate, shift (wrap), copy_region con vínculos; inbetween
   con interpolación de posiciones. Tests.
6. **Ver, leer y exportar**: render (PNG, escala automática, onion), read_pixels (leyenda, códigos de
   dos caracteres, límite 128×128), export png/gif/sequence/sheet/atlas. Tests.
7. **Binario `chimpsprite-mcp`**: rmcp stdio, una herramienta por operación con descripciones claras,
   errores como `isError`, `--root`; test de integración por stdio; `.mcp.json`, README, CI (wasm
   check de cs-agent).
8. **Prueba real**: conectar el servidor a Claude Code, dibujar y animar un sprite por MCP, mostrar el
   resultado en la app.
