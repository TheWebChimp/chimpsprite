## Desviaciones/decisiones (tomadas al planear)

- **El clic derecho ya existe:**
  - Hoy `tool_group` (`panels.rs`) llama a `response.context_menu(...)`, así que el clic derecho
    ya abre la lista. Lo nuevo es mantener presionado.
  - Las dos formas se juntan en un solo popup, `variants_popup`, con el mismo id que usaba
    `context_menu` (`Popup::default_response_id`).
  - **Mantener presionado:**
    - Cuenta solo con el botón principal, y solo en grupos con más de una herramienta.
    - Al cumplirse 400 ms se abre la lista junto al puntero, sin esperar a soltar.
    - Al soltar, ese clic no elige la herramienta ni cierra la lista: ese frame usa
      `PopupCloseBehavior::IgnoreClicks`.
    - Mientras está presionado se pide un repintado para cuando se cumpla el tiempo, porque sin
      eventos egui no vuelve a pintar.
  - El botón `⏷` es otro popup (`menu_button`) y sigue igual.
  - `tool_group` pasa a devolver la `Response` del botón, para los tests.
- **Un paso de undo por trazo:**
  - Pencil, Jumble y Spray ya juntan todo el trazo en un solo `DrawPixels`, que se ejecuta al
    soltar. La vista previa aplica `preview()` sobre un clon.
  - Contour y Blur hacen lo mismo, así que no hace falta `execute_grouped`.
- **Blur lee los píxeles "actuales":**
  - Durante el trazo el documento no cambia. La herramienta guarda en `done` lo que ya suavizó
    en este trazo y lee de ahí. Lo que todavía no tocó lo lee de la capa.
  - Cada aplicación calcula primero todos los promedios y después los escribe, así el orden de
    recorrido no sesga el resultado.
  - En indexado cada aplicación ya guarda el índice de la paleta. Las pasadas siguientes leen el
    color que se ve.
  - Al final se descartan los píxeles que quedaron igual que en la capa. Si no cambió nada, no
    hay comando ni paso de undo (por ejemplo, en un área de un solo color).
  - Blur no usa `tick`: con el puntero quieto no vuelve a aplicar.
- **Blur y la selección:**
  - La herramienta solo suaviza píxeles seleccionados, así las pasadas no acumulan valores que
    no se van a escribir.
  - Los vecinos fuera de la selección sí se leen.
  - El recorte de `shape_paint` también se aplica, aunque ya no recorta nada.
- **Simetría:** se agrega `ToolKind::mirrors()`, que vale para las herramientas que pintan menos
  Text (como hoy) y Blur. `shape_paint` la usa en vez de comparar con `ToolKind::Text`.
- **`nearest_index`:**
  - `cs-tools` no depende de `cs-io`, y `cs-raster` tampoco. Por eso la función pasa a `cs-core`
    como `Palette::nearest(&self, c, transparent_index) -> u8`, con la misma lógica (alfa < 128 da
    el índice transparente).
  - `cs_io::import::nearest_index` queda como envoltorio, así `clipboard.rs` y la importación no
    cambian.
- **`blur_average` es pura:** recibe un `get(Point) -> Option<Rgba>` (`None` fuera del lienzo) y
  devuelve `Rgba`. El paso a `PixelValue` y a índice lo hace `cs_tools::Blur`. Por eso el test
  "en indexado da el índice más cercano" está en `cs-tools`, no en `cs-raster`.
- **Contour:**
  - Los vértices del polígono son todos los puntos del trazo, ya interpolados con Bresenham, y
    pasan a `polygon_filled`.
  - No usa el tamaño de pincel ni pixel-perfect: la vista previa y el borde miden 1 px, como en
    Aseprite. No entra en `uses_brush`.
  - No se pega a guías ni a la grilla, igual que el lápiz.
- **Capas bloqueadas:** `DrawPixels` falla con `CmdError::LayerLocked` y `execute` devuelve
  `false`. Contour y Blur no hacen nada, igual que las demás herramientas.
- **Modo Tiles:**
  - Contour y Blur entran en `blocked_in_tiles`. La barra de estado ya dice "Not available in
    Tiles mode".
  - Hand no está bloqueada.
- **Máscara de capa (`edit_mask`):**
  - Contour pinta niveles, como el lápiz (`to_mask_command`).
  - Blur se comporta como Jumble: lee los colores de la capa y escribe niveles. No se trata
    aparte en esta entrega.
- **Hand en el lienzo:**
  - En `CanvasView::handle_input`, Hand cuenta como Espacio mantenido:
    `let space = ... || editor.active_tool() == ToolKind::Hand`. Así aplica el mismo código y
    las mismas reglas:
    - El botón principal mueve la vista.
    - No llega ninguna presión a la herramienta, así que no se activan artboards ni se confirma
      lo flotante.
    - No hay guías ni handles de simetría, ni autoscroll, ni contorno del pincel.
  - El botón derecho con Hand no hace nada. El del medio mueve la vista, como siempre.
  - El cursor es `Grabbing` mientras se arrastra, con Hand y también con Espacio. Hoy Espacio
    muestra `Grab` todo el tiempo: es una mejora chica y coherente.
  - Elegir Hand confirma lo flotante, como cualquier `set_tool`.
- **Íconos de la toolbar con nombres:**
  - Hand toma `✋`, que hoy usa Move, porque es una mano.
  - Move pasa a `✚`, parecido a la cruz de flechas de Aseprite.
  - Contour usa `➿` y Blur usa `☁`.
  - La toolbar de solo íconos es otra entrega.
- **Contorno del pincel:** Blur no lo rellena con el color primario, igual que Eraser y Bucket,
  porque no pinta un color.
- **"Harness":**
  - El lienzo ya tiene `Harness` en `canvas.rs`, con eventos crudos y `ctx.run_ui`.
  - Para la toolbar se arma algo igual en los tests de `panels.rs` (`group_frame`). No hay
    `egui_kittest` en el proyecto.

```rust
    /// Índice del color más cercano (distancia euclidiana RGB), sin contar `transparent_index`.
    /// Con alfa < 128, o si no hay otro color, devuelve `transparent_index`.
    pub fn nearest(&self, c: Rgba, transparent_index: u8) -> u8 {
        if c.a < 128 {
            return transparent_index;
        }
        let dist = |p: &Rgba| {
            let d = |a: u8, b: u8| (a as i32 - b as i32).pow(2);
            d(p.r, c.r) + d(p.g, c.g) + d(p.b, c.b)
        };
        self.colors
            .iter()
            .enumerate()
            .filter(|(i, _)| *i as u8 != transparent_index)
            .min_by_key(|(_, p)| dist(p))
            .map_or(transparent_index, |(i, _)| i as u8)
    }
```

```rust
mod tests {

    use super::*;

    /// Lienzo de `w`×`h` transparente con algunos píxeles pintados.
    fn canvas(w: i32, h: i32, painted: &[(Point, Rgba)]) -> impl Fn(Point) -> Option<Rgba> {

            (p.0 >= 0 && p.1 >= 0 && p.0 < w && p.1 < h).then(|| {
```

```rust
use cs_core::Rgba;

use crate::Point;

/// Promedio del vecindario de 3×3 de `p`. El color se pondera por alfa y el alfa es el promedio
/// simple. `get` devuelve `None` fuera del lienzo: esos vecinos no cuentan.
pub fn blur_average(p: Point, get: impl Fn(Point) -> Option<Rgba>) -> Rgba {
    let (mut n, mut a, mut r, mut g, mut b) = (0u32, 0u32, 0u32, 0u32, 0u32);
    for dy in -1..=1 {
        for dx in -1..=1 {
            let Some(c) = get((p.0 + dx, p.1 + dy)) else {
                continue;
            };
            let ca = c.a as u32;
            n += 1;
            a += ca;
            r += c.r as u32 * ca;
            g += c.g as u32 * ca;
            b += c.b as u32 * ca;
        }
    }
    let alpha = if n == 0 { 0 } else { (a + n / 2) / n };
    if alpha == 0 {
        return Rgba::TRANSPARENT;
    }
    // Con alfa > 0 la suma `a` no es 0. Redondeo al entero más cercano.
    let channel = |sum: u32| ((sum + a / 2) / a) as u8;
    Rgba::new(channel(r), channel(g), channel(b), alpha as u8)
}
```

```rust
/// Contorno a mano alzada: al soltar se cierra (del último punto al primero) y se rellena con el
/// contorno incluido. La vista previa es el trazo de 1 px; no usa el tamaño de pincel.

pub struct Contour {
    path: Vec<Point>,
}

impl Contour {
    pub fn new() -> Self {
        Self::default()
    }
}

impl Tool for Contour {
    fn press(&mut self, _ctx: &ToolContext, p: Point) {
        self.path = vec![p];
    }

    fn drag(&mut self, _ctx: &ToolContext, p: Point) {
        let Some(&last) = self.path.last() else {
            return;
        };
        if last != p {
            self.path.extend(line(last, p).into_iter().skip(1));
        }
    }

    fn release(&mut self, ctx: &ToolContext) -> ToolOutput {
        if self.path.is_empty() {
            return ToolOutput::default();
        }
        // Un solo punto da un píxel; un trazo sin área queda como el trazo.
        let out = ToolOutput::command(ctx.draw(polygon_filled(&self.path), ctx.color));
        self.path.clear();
        out
    }

    fn preview(&self, ctx: &ToolContext) -> ToolOutput {
        if self.path.is_empty() {
            return ToolOutput::default();
        }
        ToolOutput::command(ctx.draw(self.path.iter().copied(), ctx.color))
    }

    fn is_active(&self) -> bool {
        !self.path.is_empty()
    }
}
```

```rust
use std::collections::HashMap;

use cs_core::{ColorMode, PixelValue, Rgba};
use cs_raster::{Point, blur_average, brush_square, line};

use crate::{Tool, ToolContext, ToolOutput};

/// Pincel que suaviza: cada píxel bajo el pincel toma el promedio de su vecindario de 3×3. Las
/// pasadas del mismo trazo se acumulan; no usa la simetría (como en Aseprite).
#[derive(Debug, Default)]
pub struct Blur {
    active: bool,
    at: Point,
    /// Lo ya suavizado en este trazo. El documento no cambia hasta soltar, así que lo demás se
    /// lee de la capa.
    done: HashMap<Point, PixelValue>,
}

impl Blur {
    pub fn new() -> Self {
        Self::default()
    }

    /// Color resuelto de `p` en este momento del trazo; `None` fuera del lienzo.
    fn current(&self, ctx: &ToolContext, p: Point) -> Option<Rgba> {
        if !ctx.in_canvas(p) {
            return None;
        }
        let value = self
            .done
            .get(&p)
            .copied()
            .unwrap_or_else(|| ctx.sprite.pixel(ctx.layer, ctx.frame, p.0, p.1));
        Some(cs_render::resolve(ctx.sprite, value))
    }

    /// Una aplicación del pincel en `center`. Primero calcula todos los promedios con los
    /// colores de antes y después los guarda: así el orden de recorrido no sesga el resultado.
    fn apply(&mut self, ctx: &ToolContext, center: Point) {
        let updates: Vec<(Point, PixelValue)> = brush_square(center, ctx.brush_size)
            .into_iter()
            .filter(|&p| ctx.in_canvas(p))
            .filter(|&(x, y)| ctx.selection.is_none_or(|m| m.contains(x, y)))
            .map(|p| (p, to_value(ctx, blur_average(p, |q| self.current(ctx, q)))))
            .collect();
        self.done.extend(updates);
    }
}

/// Promedio → valor de píxel. En indexado, el índice más cercano de la paleta (con alfa < 128,
/// el transparente).
fn to_value(ctx: &ToolContext, c: Rgba) -> PixelValue {
    match ctx.sprite.color_mode {
        ColorMode::Rgba => PixelValue::Rgba(c),
        ColorMode::Indexed { transparent_index } => {
            PixelValue::Index(ctx.sprite.palette.nearest(c, transparent_index))
        }
    }
}

impl Tool for Blur {
    fn press(&mut self, ctx: &ToolContext, p: Point) {
        self.active = true;
        self.at = p;
        self.done.clear();
        self.apply(ctx, p);
    }

    fn drag(&mut self, ctx: &ToolContext, p: Point) {
        if !self.active || p == self.at {
            return;
        }
        for q in line(self.at, p).into_iter().skip(1) {
            self.apply(ctx, q);
        }
        self.at = p;
    }

    fn release(&mut self, ctx: &ToolContext) -> ToolOutput {
        let out = self.preview(ctx);
        self.active = false;
        self.done.clear();
        out
    }

    fn preview(&self, ctx: &ToolContext) -> ToolOutput {
        if !self.active {
            return ToolOutput::default();
        }
        // Solo lo que cambió: sin cambios no hay comando (ni paso de undo).
        let mut pixels: Vec<(i32, i32, PixelValue)> = self
            .done
            .iter()
            .filter(|&(&(x, y), &v)| v != ctx.sprite.pixel(ctx.layer, ctx.frame, x, y))
            .map(|(&(x, y), &v)| (x, y, v))
            .collect();
        if pixels.is_empty() {
            return ToolOutput::default();
        }
        pixels.sort_unstable_by_key(|&(x, y, _)| (y, x));
        ToolOutput::command(cs_commands::Command::DrawPixels {
            layer: ctx.layer,
            frame: ctx.frame,
            pixels,
        })
    }

    fn is_active(&self) -> bool {
        self.active
    }
}
```

```rust
/// Mantener presionado el botón de un grupo este tiempo (en segundos) abre la lista de variantes.
const LONG_PRESS_S: f64 = 0.4;

/// Qué pasa con el botón de un grupo mantenido presionado, en este frame.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum Hold {
    /// Nada que hacer.
    Idle,
    /// Se cumplió el tiempo: abrir la lista.
    Open,
    /// Se suelta el botón con la lista abierta por esta presión: el clic no elige ni cierra.
    Release,
}

/// Lleva la cuenta de una presión larga con el botón principal sobre `response`.
fn hold_state(ui: &egui::Ui, response: &egui::Response) -> Hold {
    let id = response.id.with("long_press");
    let opened = ui.data(|d| d.get_temp::<bool>(id)).unwrap_or(false);
    let (down, held) = ui.input(|i| {
        let held = i.pointer.press_start_time().map(|t| i.time - t);
        (i.pointer.primary_down(), held.unwrap_or(0.0))
    });
    if down && response.is_pointer_button_down_on() {
        if opened {
            return Hold::Idle;
        }
        if held >= LONG_PRESS_S {
            ui.data_mut(|d| d.insert_temp(id, true));
            return Hold::Open;
        }
        // Sin eventos egui no vuelve a pintar: pide un frame para cuando se cumpla el tiempo.
        ui.ctx()
            .request_repaint_after_secs((LONG_PRESS_S - held) as f32);
        return Hold::Idle;
    }
    if opened {
        ui.data_mut(|d| d.remove::<bool>(id));
        return Hold::Release;
    }
    Hold::Idle
}

/// Lista de variantes de un grupo junto al puntero. Se abre con clic derecho o manteniendo
/// presionado, y un clic normal en el botón la cierra. Usa el mismo id que `context_menu`.
fn variants_popup(response: &egui::Response, hold: Hold, add_contents: impl FnOnce(&mut egui::Ui)) {
    use egui::{Popup, PopupCloseBehavior, SetOpenCommand};
    let open = if hold == Hold::Open || response.secondary_clicked() {
        Some(SetOpenCommand::Bool(true))
    } else if response.clicked() && hold != Hold::Release {
        Some(SetOpenCommand::Bool(false))
    } else {
        None
    };
    let mut popup = Popup::menu(response).open_memory(open).at_pointer_fixed();
    if hold == Hold::Release {
        // Soltar el botón cuenta como clic: no tiene que cerrar la lista recién abierta.
        popup = popup.close_behavior(PopupCloseBehavior::IgnoreClicks);
    }
    popup.show(add_contents);
}

/// Fila de un grupo: la herramienta actual del grupo y, si hay más, un desplegable con las demás
/// (también con clic derecho o manteniendo presionado), como en Aseprite. Devuelve la respuesta
/// del botón.
fn tool_group(
    ui: &mut egui::Ui,
    editor: &mut Editor,
    index: usize,
    group: &[ToolKind],
) -> egui::Response {
    let memory = ui.id().with(("tool_group", index));
    if group.contains(&editor.tool) {
        ui.data_mut(|d| d.insert_temp(memory, editor.tool));
    }
    let shown = ui
        .data(|d| d.get_temp::<ToolKind>(memory))
        .unwrap_or(group[0]);
    let mut pick = None;
    let response = ui
        .horizontal(|ui| {
            let more = group.len() > 1;
            ui.spacing_mut().item_spacing.x = 2.0;
            let width = ui.available_width() - if more { 22.0 } else { 0.0 };
            let label = format!("{} {}", icon(shown), shown.label());
            let button = egui::Button::selectable(editor.tool == shown, label)
                .shortcut_text("")
                .truncate();
            let response = ui.add_sized([width, 24.0], button).on_hover_text(format!(
                "{} ({})",
                shown.label(),
                shown.shortcut()
            ));
            let hold = if more {
                hold_state(ui, &response)
            } else {
                Hold::Idle
            };
            if response.clicked() && hold != Hold::Release {
                pick = Some(shown);
            }
            if more {
                let current = editor.tool;
                variants_popup(&response, hold, |ui| group_menu(ui, current, group, &mut pick));
                ui.menu_button("⏷", |ui| group_menu(ui, current, group, &mut pick))
                    .response
                    .on_hover_text("More tools (or right-click, or hold)");
            }
            response
        })
        .inner;
    if let Some(kind) = pick {
        editor.set_tool(kind);
    }
    response
}
```

`toolbar` no cambia: el `for` sigue llamando a `tool_group(ui, editor, index, group);`. La
`Response` que se descarta no da warning, porque `Response` no es `#[must_use]`. Si clippy dijera
lo contrario, se escribe `let _ = tool_group(...)`.
