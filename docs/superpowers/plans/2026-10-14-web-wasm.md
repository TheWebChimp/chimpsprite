# Web / WASM — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** La app completa en el navegador, publicada en GitHub Pages.

**Architecture:** Módulo `platform` en `cs-ui` (escritorio/web) para abrir, guardar y descargar; el resto
de la app no distingue plataforma. Entrada wasm en `apps/chimpsprite` con `eframe::WebRunner`; build con
trunk; deploy con GitHub Actions.

Spec: `docs/superpowers/specs/2026-10-14-web-wasm-design.md`

## Global Constraints

- Escritorio sin regresiones: mismos atajos, diálogos nativos y guardado atómico.
- Todo `cfg(target_arch = "wasm32")` vive en `platform` (y en `main.rs`); el resto del código no se
  bifurca por plataforma.
- `cargo check --target wasm32-unknown-unknown -p chimpsprite` pasa en CI.

---

### Task 1: `platform` + refactor de archivos
- `files::decode(name, bytes)` / `files::encode(doc, file_name)` puros (sin `std::fs`).
- `platform::{Platform, PlatformEvent, SaveTarget}`: `open_file`, `open_dropped`, `choose_save`,
  `write`, `poll`. Escritorio: `rfd` síncrono + `files::write_atomic`; web: `rfd::AsyncFileDialog` +
  `spawn_local`, descarga por Blob.
- `ChimpApp`: `DocLocation { name, target: Option<SaveTarget> }`; abrir procesa `PlatformEvent::Opened`.
- `ExportDialog::build(editor, stem) -> Vec<(String, Vec<u8>)>` puro; escribir vía `platform`.
- Tests: decode/encode por extensión; `SaveTarget::{stem, sibling}`; nombres de export.

### Task 2: Entrada web
- `main.rs` con `cfg` (nativo: igual; wasm: `WebRunner` sobre `<canvas id="chimpsprite">`, logger web).
- Dependencias wasm: `wasm-bindgen-futures`, `web-sys` (Blob, Url, HtmlAnchorElement, Storage,
  Window, Location), `js-sys`; wgpu con WebGL2 como respaldo.
- `index.html` con pantalla de carga y mensaje de error; `Trunk.toml`.
- `?demo` en la URL.

### Task 3: Web: autosave, restaurar sesión, aviso al salir
- Autosave en `localStorage` (base64 de `.chimp`, tope 4 MB) cada 10 s si hay cambios.
- Diálogo "Restore last session" al iniciar.
- `beforeunload` mientras haya cambios sin guardar.
- Tests (escritorio) de codificación y tope.

### Task 4: CI y deploy
- CI: `cargo check --target wasm32-unknown-unknown -p chimpsprite`.
- `.github/workflows/pages.yml` (trunk build + deploy-pages) y Pages en modo Actions.
- Verificar el sitio publicado.
