# UI en pixel art (base y diálogo "Unsaved changes"): plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un interruptor View → Pixel UI que pone la fuente pixel del usuario a 16, una escala
entera de UI (1×/2×/3×) y dibuja el diálogo "Unsaved changes" con el skin de `skin.aseprite`
(marco en 9-slice y botones copiados del mockup). Apagado, todo queda como hoy.

**Architecture:**
- **`assets/ui/`:** `skin.aseprite` (con los botones del mockup ya copiados) y `chimpsprite.ttf`,
  embebidos con `include_bytes!`.
- **`cs-ui::skin`** (módulo público):
  - `nine.rs`: geometría pura del 9-slice, sin egui.
  - `mod.rs`: `decode` (puro: `.aseprite` → recortes y colores) y `Skin` (texturas `NEAREST`,
    variantes con caída a la base, colores con caída al tema).
  - `watch.rs`: recarga en vivo con `CHIMPSPRITE_SKIN` (solo escritorio).
- **`cs-ui::appearance`:** fuentes, estilo sin redondeo, `pixels_per_point` entero y el estado
  `PixelUi` que `ChimpApp::ui` actualiza una vez por frame.
- **`cs-ui::pixel_ui`:** `pixel_dialog` y `pixel_button`, con respaldo plano si falta la pieza.
- **`file_actions.rs`:** "Unsaved changes" separa los textos, el dibujo (egui o pixel) y la
  lógica, que es la misma en los dos modos.

**Tech Stack:** Rust 2024, egui/eframe 0.36, Aseprite 1.3 en modo batch (solo para la Task 1).

**Spec:** `docs/superpowers/specs/2026-10-23-pixel-ui-design.md`.

## Global Constraints

- **Crates del motor:** `cs-core`, `cs-raster`, `cs-commands`, `cs-tools` y `cs-io` no dependen de
  egui y compilan en wasm32. Este plan no los toca: el skin se lee con `cs_io::aseprite::read` y
  `cs_render::render_frame`, que ya existen.
- **Geometría 9-slice:** va en `crates/cs-ui/src/skin/nine.rs`, un módulo puro sin tipos de egui,
  igual que `transform_box.rs`. Así queda junto a su único usuario, el skin. `cs-raster` es para
  los píxeles del sprite, no para la UI.
- **Idiomas:** código y comentarios en español; textos de la UI en inglés. Imita la densidad de
  comentarios del código vecino.
- **Glifos:**
  - Cada glifo de la UI tiene que existir en las fuentes por defecto de egui o en
    `chimpsprite.ttf`.
  - `chimpsprite.ttf` tiene `×`, `·`, `°`, `¿`, `¡`, `€` y `áéíóúñ`, y le faltan `•`, `…`, `—`,
    `▸` y `✓` (revisado con fontTools).
  - Las fuentes de egui quedan detrás de la pixel como respaldo, así que `•` se sigue viendo,
    pero con otra fuente. Por eso el diálogo pixel usa `·`.
  - Los textos nuevos de este plan (`Pixel UI`, `UI Scale`, `1×`/`2×`/`3×`) solo usan glifos de
    las dos fuentes.
- **egui 0.36:**
  - `CentralPanel::show` recibe `&mut Ui`, y `Area::show` y `Window::show` reciben `&Context`.
  - `Margin` usa `i8`.
  - El estilo se lee con `ctx.style_of(Theme::Dark)`. `Context::style` no existe.
  - `set_pixels_per_point` se traduce a `set_zoom_factor(ppp / native_ppp)` y vale desde el
    frame siguiente.
  - `Options::zoom_factor` se guarda entre sesiones.
- **Toolchain aislado:** antes de cualquier comando cargo, en Git Bash:
  `export RUSTUP_HOME=/d/Work/chimpdeas/.rust-toolchain/rustup CARGO_HOME=/d/Work/chimpdeas/.rust-toolchain/cargo; export PATH=$CARGO_HOME/bin:$PATH`
- **Verificación por tarea:** `cargo fmt --all` y los tests del crate tocado (`cargo test -p cs-ui`).
- **Verificación final:**
  - `cargo clippy --workspace --all-targets -- -D warnings`
  - `cargo test --workspace`
  - `cargo check -p cs-ui --target wasm32-unknown-unknown`
- **GUI:**
  - Compilar solo en `CARGO_TARGET_DIR=target/gui-pixel`, nunca en el target por defecto.
  - Antes de abrir la app, copiar `%APPDATA%/ChimpSprite/data/app.ron` y restaurarlo al
    terminar.
- **`.design/`:** no se modifica nada adentro. Los archivos se **copian** a `assets/ui/`.
  `Design.aseprite` solo se abre para leer.
- **Commits:** terminan con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

- **Rama:** `pixel-ui`. No cambiar de rama.

## Desviaciones/decisiones (tomadas al planear)

- **El marco del diálogo es `window`, no `window.active`:**
  - En `skin.aseprite`, `window` es la ventana de barra rosa (226,114,133) y borde negro: es
    igual, píxel por píxel, al diálogo del mockup (frame 0, (54,334)–(226,408)).
  - `window.active` está dibujada con una barra apagada (183,120,130) y borde gris.
  - Como la prueba manual pide que el diálogo "se vea como el mockup", `pixel_dialog` usa
    `window`. Si el usuario quiere la otra, se cambia la constante `DIALOG_PIECE`.
- **Botones del mockup:**
  - El diálogo del mockup tiene tres botones de 49 px de ancho. Todos apoyan en la fila 403, y
    se distinguen por la sombra:
    - (166,387) mide 49×17, con sombra de 1 px: es el **normal** → `button`.
    - (114,386) mide 49×18, está más alto y con sombra de 2 px: es **hover** → `button.hover`.
    - (59,388) mide 49×16, está hundido, sin sombra y con el borde más claro: es **presionado**
      → `button.down`.
  - Se copian los tres como piezas de 49×18 con el rectángulo (x, 386, 49, 18). Lo que está por
    fuera del contorno queda transparente: las esquinas redondeadas y las filas de arriba de los
    botones más bajos. Así los tres estados comparten la base y el texto no salta.
  - Centro 9-slice `(3, 4, 43, 10)`. Las filas 4–13 y las columnas 3–45 son lisas en los tres
    estados, así que las esquinas y las sombras no se deforman.
  - Los slices viejos (32×16 en y=76) no tienen lugar para piezas de 49 px. Se mueven a una fila
    libre: `button` (4,176), `button.hover` (57,176) y `button.down` (110,176).
  - El botón suelto de (72,468) no se usa. Tiene un contorno exterior extra, pensado para ir
    sobre el fondo azul del escritorio.
- **`pixel_dialog` y `pixel_button` reciben `&Skin`.** Firmas:
  - `pixel_dialog(ctx, skin, id, title, add_contents)`
  - `pixel_button(ui, skin, label)`

  El skin vive en `ChimpApp` (`PixelUi`). Pasarlo explícito evita guardarlo en la memoria de
  egui.
- **`skin` es `pub mod`** (`cs_ui::skin`):
  - Sus tipos (`SkinColors` con 8 colores, `WidgetState::Active`, etc.) existen por el spec,
    aunque esta entrega no los use todos. Como módulo privado darían `dead_code` con
    `-D warnings`.
  - La lectura se separa en dos partes. `decode` es puro y devuelve `SkinData`, así que se
    prueba sin GPU. `Skin::load`/`from_data` suben las texturas.
- **Escala:**
  - Un píxel del skin mide un punto, y `pixels_per_point = ui_scale`. `PixelUi::update` llama a
    `ctx.set_pixels_per_point(scale)` en cada frame. No hace nada si ya está, y corrige solo si
    cambia la escala del sistema (otro monitor), porque egui lo traduce a
    `zoom = scale / native`.
  - Con Pixel UI encendido se apaga `zoom_with_keyboard`, porque el Ctrl+/- de egui rompería la
    escala entera. Al apagar Pixel UI vuelve el valor por defecto (encendido en escritorio,
    apagado en la web) y `zoom_factor` vuelve a 1.0, o sea, a la escala del sistema.
  - El 9-slice se calcula en píxeles físicos (`scale = round(ppp)`) y se vuelve a puntos para
    pintar, así todo cae en píxeles enteros de pantalla.
- **Fuente:**
  - Se registra como `chimpsprite`, primera de la familia proporcional, con `hinting: Some(false)`
    porque los contornos ya caen en la grilla.
  - Small, Body, Button y Heading pasan a 16 proporcional. Monospace no cambia.
  - Se revisó epaint 0.36: las posiciones de galley, fila y glifo se redondean a píxeles físicos
    y el ascent de la fuente redondeado es 11, así que no hace falta `y_offset`.
- **"El color de texto sale del skin"** se aplica solo dentro de las piezas pixel
  (`pixel_dialog`, `pixel_button`). `color.text` es casi negro (5,4,3) y el resto de la app
  sigue con el tema oscuro hasta que se migre: ahí no se leería.
- **El lienzo no se toca.** Su zoom sigue en puntos: con UI a 2×, un sprite al 100% muestra cada
  píxel con 2 píxeles de pantalla. Es lo mismo que ya pasa hoy con la escala del sistema. El nivel
  de zoom no cambia al cambiar la escala de la UI.
- **Recarga en vivo:**
  - `PixelUi::update` la revisa desde `ChimpApp::ui`, solo con Pixel UI encendido. Pide
    `request_repaint_after(1 s)` para revisar aunque no haya eventos.
  - El archivo se lee solo si cambió su fecha de modificación.
  - Si el archivo está roto, se queda el skin anterior y se avisa en el log una vez por cambio.
  - Si el archivo no existe, se avisa una vez.
  - Si el skin embebido no se puede leer, se usa `Skin::fallback()`: todo plano, con los colores
    del tema.
- **Botón:**
  - El alto es el de la pieza, 18 px: las piezas están pensadas para una línea de la fuente.
  - El ancho es: borde + 4 + texto + 4 + borde, sin bajar del ancho de la pieza.
  - El texto va centrado en el área del centro y no se mueve con el estado. Se afina después.
  - Con foco se dibuja un contorno de 1 px `accent`.
- **Lista de documentos** en el diálogo pixel: `· nombre` en vez de `• nombre`, porque `•` no
  está en la fuente pixel.
- **Teclas del diálogo:** Esc cancela en los dos modos, como hoy. Enter no hace nada, igual que
  hoy.
- **Tests del diálogo:**
  - `ChimpApp::new` pasa a usar `ChimpApp::with_parts(recent, view, palettes)`, que los tests
    llaman con un `PresetStore` vacío.
  - Los botones se encuentran por nombre en el árbol de accesibilidad de egui. cs-ui ya compila
    con `accesskit`, y `pixel_button` llama a `widget_info`. Los bounds de accesskit están en
    puntos.
- **View → Pixel UI está dentro del menú View**, que hoy solo se habilita con un documento
  abierto. En Home no se puede cambiar; queda así en esta entrega.
- **`.gitattributes`:** se agrega `*.ttf binary`.

Crear `/tmp/chimpsprite-copy-buttons.lua`:

```lua
-- Copia los botones del mockup (Design.aseprite, frame 0) a los slices button* del skin.
-- Uso: Aseprite.exe -b --script-param design=<Design.aseprite> --script-param skin=<skin.aseprite>
--      --script chimpsprite-copy-buttons.lua
-- Design.aseprite solo se lee: se aplana en memoria y se cierra sin guardar.
local designPath = app.params["design"]
local skinPath = app.params["skin"]
assert(designPath and skinPath, "faltan --script-param design=... y skin=...")

-- Cuerpo del diálogo en el mockup: lo que queda por fuera del contorno de cada botón.
local BG = app.pixelColor.rgba(234, 224, 221, 255)
local CLEAR = app.pixelColor.rgba(0, 0, 0, 0)
-- Los tres estados miden 49x18 y apoyan en la misma fila (403): el texto no salta.
local W, H = 49, 18
local BUTTONS = {
  -- Sombra de 1 px: el botón en reposo.
  { slice = "button",       src = { x = 166, y = 386 }, dst = { x = 4,   y = 176 } },
  -- Más alto, sombra de 2 px: puntero encima.
  { slice = "button.hover", src = { x = 114, y = 386 }, dst = { x = 57,  y = 176 } },
  -- Hundido, sin sombra: presionado.
  { slice = "button.down",  src = { x = 59,  y = 386 }, dst = { x = 110, y = 176 } },
}
-- Esquinas y sombras fijas; filas 4-13 y columnas 3-45 lisas en los tres estados.
local CENTER = Rectangle(3, 4, 43, 10)

-- Mockup aplanado (el frame 1 de Lua es el frame 0).
local design = app.open(designPath)
local flat = Image(design.spec)
flat:drawSprite(design, 1)
design:close()

local skin = app.open(skinPath)
local layer
for _, l in ipairs(skin.layers) do
  -- "Skin (dibuja aquí)": se compara el prefijo para no depender del acento.
  if l.name:sub(1, 4) == "Skin" then layer = l end
end
assert(layer, "no está la capa 'Skin (dibuja aquí)'")

-- La capa a tamaño de lienzo (el cel puede estar recortado a lo dibujado).
local full = Image(skin.spec)
local cel = layer:cel(1)
if cel then full:drawImage(cel.image, cel.position) end

for _, b in ipairs(BUTTONS) do
  for y = 0, H - 1 do
    -- Antes del primer píxel distinto del fondo y después del último, transparente: son las
    -- esquinas redondeadas y las filas por encima de un botón más bajo.
    local first, last
    for x = 0, W - 1 do
      if flat:getPixel(b.src.x + x, b.src.y + y) ~= BG then
        first = first or x
        last = x
      end
    end
    for x = 0, W - 1 do
      local px = CLEAR
      if first and x >= first and x <= last then
        px = flat:getPixel(b.src.x + x, b.src.y + y)
      end
      full:drawPixel(b.dst.x + x, b.dst.y + y, px)
    end
  end
  local found
  for _, s in ipairs(skin.slices) do
    if s.name == b.slice then found = s end
  end
  assert(found, "no está el slice " .. b.slice)
  found.bounds = Rectangle(b.dst.x, b.dst.y, W, H)
  found.center = CENTER
end

skin:newCel(layer, 1, full, Point(0, 0))
skin:saveAs(skinPath)
skin:close()
print("ok")
```

```markdown
# Assets de la UI en pixel art

Se compilan dentro del binario (`include_bytes!` en `crates/cs-ui`).

## chimpsprite.ttf

Fuente pixel de ChimpSprite, hecha por el autor del proyecto ("Chimp"). Se distribuye con la
misma licencia que el repositorio (MIT o Apache-2.0, a elección; ver `LICENSE-MIT` y
`LICENSE-APACHE` en la raíz).

- Grilla de 16 píxeles por em: se usa a 16 puntos, un píxel de la grilla por punto.
- Mayúsculas de 7 px; las colas bajan 2 px.
- Incluye acentos, ñ, ¿, ¡, € y °. Los glifos que no tiene (•, …, ▸) salen de las fuentes de egui.

## skin.aseprite

Las piezas de la interfaz. Se dibujan en la capa **"Skin (dibuja aquí)"**; la capa "Guías" queda
oculta.

- **Piezas:** cada una es un slice con nombre (View → Slices en Aseprite). Importa el nombre, no
  la posición: para cambiar el tamaño de una pieza, se cambia su slice.
- **9-slice:** las piezas que se estiran (`window`, `button`, `panel`, `menubar`, `tab`,
  `tool.slot`…) tienen un centro.
  - Las esquinas no se deforman.
  - Los bordes se estiran a lo largo.
  - El centro se estira en las dos direcciones.
  - En `window`, la franja de arriba del centro es la barra de título (13 px).
- **Colores:** los slices `color.*` (`desktop`, `text`, `text_dim`, `accent`, `panel`,
  `outline`, `selection`, `scroll`) dan el color de su píxel central.
- **Variantes:** `.hover`, `.down` y `.active` son opcionales; si falta una, se usa la pieza
  base.
- **Piezas sin dibujar:** una pieza totalmente transparente cuenta como que no existe; la app
  dibuja un respaldo plano con los colores del skin.
- **Íconos:** `icon.<herramienta>` miden 16×16; `tool.slot` es el marco detrás del ícono.
- **Botones:** `button`, `button.hover` y `button.down` vienen del mockup del diálogo "Unsaved
  changes".

### Probar cambios en vivo (escritorio)

    CHIMPSPRITE_SKIN=/ruta/a/skin.aseprite cargo run -p chimpsprite

Con Pixel UI encendido, la app vuelve a leer ese archivo al guardarlo (lo revisa una vez por
segundo). Si el archivo tiene un error, se queda el skin anterior y lo avisa en el log.
```

//! Geometría del 9-slice: qué parte de una pieza del skin va a qué parte del destino. Pura, sin
//! egui, en píxeles enteros (de la pieza y de la pantalla).

/// Rectángulo en píxeles enteros. Con `w` o `h` en 0 está vacío.
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct IRect {
    pub x: i32,
    pub y: i32,
    pub w: i32,
    pub h: i32,
}

impl IRect {
    pub const fn new(x: i32, y: i32, w: i32, h: i32) -> Self {
        Self { x, y, w, h }
    }

    pub fn is_empty(&self) -> bool {
        self.w <= 0 || self.h <= 0
    }
}

/// Centro del 9-slice, relativo a la pieza: lo que se estira en las dos direcciones. Alrededor
/// quedan las esquinas (fijas) y los bordes (se estiran a lo largo).
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Rect9 {
    pub x: u32,
    pub y: u32,
    pub w: u32,
    pub h: u32,
}

impl Rect9 {
    /// El centro de un slice; `None` si se sale de la pieza de tamaño `size`.
    pub fn new(x: i32, y: i32, w: u32, h: u32, size: [u32; 2]) -> Option<Self> {
        let fits = x >= 0
            && y >= 0
            && (x as u32).checked_add(w).is_some_and(|r| r <= size[0])
            && (y as u32).checked_add(h).is_some_and(|b| b <= size[1]);
        fits.then_some(Self {
            x: x as u32,
            y: y as u32,
            w,
            h,
        })
    }
}

/// Reparte `total` entre el borde de antes (`a`), el medio y el de después (`b`). Si los bordes no
/// entran, se achican en proporción y el medio queda en 0.
fn split(total: i32, a: i32, b: i32) -> (i32, i32, i32) {
    let total = total.max(0);
    if a + b <= total {
        return (a, total - a - b, b);
    }
    // Acá `a + b > total >= 0`: no se divide por cero.
    let first = (total as i64 * a as i64 / (a + b) as i64) as i32;
    (first, 0, total - first)
}

/// Los 9 pares `(origen en la pieza, destino)`, fila por fila desde la esquina de arriba a la
/// izquierda. `scale` es cuántos píxeles de pantalla mide un píxel de la pieza.
///
/// Las esquinas conservan su tamaño ×`scale`. Los bordes se estiran a lo largo y el centro en las
/// dos direcciones. Si `dest` es más chico que las esquinas, se achican para no salirse.
pub fn nine_slice(dest: IRect, size: [u32; 2], center: Rect9, scale: u32) -> [(IRect, IRect); 9] {
    let s = scale.max(1) as i32;
    let (w, h) = (size[0] as i32, size[1] as i32);
    let (cx, cy) = (center.x as i32, center.y as i32);
    let (cw, ch) = (center.w as i32, center.h as i32);
    let (right, bottom) = (w - cx - cw, h - cy - ch);
    let src_x = [(0, cx), (cx, cw), (cx + cw, right)];
    let src_y = [(0, cy), (cy, ch), (cy + ch, bottom)];
    let (l, mw, r) = split(dest.w, cx * s, right * s);
    let (t, mh, b) = split(dest.h, cy * s, bottom * s);
    let dst_x = [(dest.x, l), (dest.x + l, mw), (dest.x + l + mw, r)];
    let dst_y = [(dest.y, t), (dest.y + t, mh), (dest.y + t + mh, b)];
    std::array::from_fn(|i| {
        let (col, row) = (i % 3, i / 3);
        (
            IRect::new(src_x[col].0, src_y[row].0, src_x[col].1, src_y[row].1),
            IRect::new(dst_x[col].0, dst_y[row].0, dst_x[col].1, dst_y[row].1),
        )
    })
}

//! Skin de la UI en pixel art: piezas y colores leídos de `assets/ui/skin.aseprite`.
//!
//! - Cada pieza es un slice con nombre; su centro, si lo tiene, es el 9-slice.
//! - Los slices `color.*` dan un color: el de su píxel central.
//! - Una pieza sin dibujar (toda transparente) cuenta como que no existe.
//! - Si falta una variante (`.hover`, `.down`, `.active`), se usa la base.

pub mod nine;

use std::collections::{BTreeMap, HashMap};

use cs_core::Rgba;
use eframe::egui::{self, Color32};

pub use nine::{IRect, Rect9, nine_slice};

use crate::theme;

/// El skin que viaja dentro del binario.
pub const EMBEDDED: &[u8] = include_bytes!("../../../../assets/ui/skin.aseprite");

/// Colores del skin (`color.<nombre>`).
pub const COLOR_NAMES: [&str; 8] = [
    "desktop",
    "text",
    "text_dim",
    "accent",
    "panel",
    "outline",
    "selection",
    "scroll",
];

#[derive(Debug, thiserror::Error)]
pub enum SkinError {
    #[error("could not read the skin: {0}")]
    Read(#[from] cs_io::IoError),
}

/// Variante de una pieza según el estado del widget.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum WidgetState {
    Normal,
    Hover,
    Down,
    Active,
}

impl WidgetState {
    fn suffix(self) -> &'static str {
        match self {
            WidgetState::Normal => "",
            WidgetState::Hover => ".hover",
            WidgetState::Down => ".down",
            WidgetState::Active => ".active",
        }
    }
}

/// Una pieza recortada del skin, todavía sin subir a la GPU.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct PieceImage {
    pub size: [u32; 2],
    /// RGBA sin premultiplicar, fila por fila.
    pub rgba: Vec<u8>,
    pub center: Option<Rect9>,
}

/// Lo que se lee de `skin.aseprite`, sin egui (se prueba sin contexto).
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct SkinData {
    pub pieces: BTreeMap<String, PieceImage>,
    /// Por nombre, sin el prefijo `color.`.
    pub colors: BTreeMap<String, Rgba>,
}

/// Lee el skin: compone el frame 0 con las capas visibles y recorta cada slice.
pub fn decode(bytes: &[u8]) -> Result<SkinData, SkinError> {
    let (sprite, _) = cs_io::aseprite::read(bytes)?;
    let pixels = cs_render::render_frame(&sprite, 0);
    let (width, height) = (sprite.width as i32, sprite.height as i32);
    let at = |x: i32, y: i32| {
        if x < 0 || y < 0 || x >= width || y >= height {
            Rgba::TRANSPARENT
        } else {
            pixels[(y * width + x) as usize]
        }
    };
    let mut data = SkinData::default();
    for slice in &sprite.slices {
        let Some(key) = slice.key_at(0) else {
            continue;
        };
        let (x, y, w, h) = key.bounds;
        if w == 0 || h == 0 {
            continue;
        }
        if let Some(name) = slice.name.strip_prefix("color.") {
            let c = at(x + w as i32 / 2, y + h as i32 / 2);
            if c.a > 0 {
                data.colors.insert(name.to_string(), c);
            }
            continue;
        }
        let mut rgba = Vec::with_capacity((w * h * 4) as usize);
        for py in y..y + h as i32 {
            for px in x..x + w as i32 {
                let c = at(px, py);
                rgba.extend_from_slice(&[c.r, c.g, c.b, c.a]);
            }
        }
        if rgba.chunks_exact(4).all(|p| p[3] == 0) {
            continue;
        }
        let center = key
            .center
            .and_then(|(cx, cy, cw, ch)| Rect9::new(cx, cy, cw, ch, [w, h]));
        data.pieces.insert(
            slice.name.clone(),
            PieceImage {
                size: [w, h],
                rgba,
                center,
            },
        );
    }
    Ok(data)
}

/// Colores del skin. Los que el skin no trae salen del tema oscuro (`theme.rs`).
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct SkinColors {
    pub desktop: Color32,
    pub text: Color32,
    pub text_dim: Color32,
    pub accent: Color32,
    pub panel: Color32,
    pub outline: Color32,
    pub selection: Color32,
    pub scroll: Color32,
}

impl SkinColors {
    pub fn from_theme() -> Self {
        Self {
            desktop: theme::CANVAS_BG,
            text: egui::Visuals::dark().strong_text_color(),
            text_dim: theme::LABEL,
            accent: theme::ACCENT,
            panel: theme::PANEL,
            outline: theme::CANVAS_BORDER,
            selection: theme::ACCENT,
            scroll: theme::WIDGET_HOVER,
        }
    }

    fn with(colors: &BTreeMap<String, Rgba>) -> Self {
        let mut c = Self::from_theme();
        let slots = [
            ("desktop", &mut c.desktop),
            ("text", &mut c.text),
            ("text_dim", &mut c.text_dim),
            ("accent", &mut c.accent),
            ("panel", &mut c.panel),
            ("outline", &mut c.outline),
            ("selection", &mut c.selection),
            ("scroll", &mut c.scroll),
        ];
        for (name, slot) in slots {
            if let Some(v) = colors.get(name) {
                *slot = Color32::from_rgba_unmultiplied(v.r, v.g, v.b, v.a);
            }
        }
        c
    }
}

/// Una pieza lista para dibujar, sin suavizado.
pub struct Piece {
    pub texture: egui::TextureHandle,
    pub size: [u32; 2],
    pub center: Option<Rect9>,
}

pub struct Skin {
    pieces: HashMap<String, Piece>,
    colors: SkinColors,
}

impl Skin {
    pub fn load(ctx: &egui::Context, bytes: &[u8]) -> Result<Skin, SkinError> {
        Ok(Self::from_data(ctx, decode(bytes)?))
    }

    /// El skin embebido; si no se puede leer, todo plano con los colores del tema.
    pub fn embedded(ctx: &egui::Context) -> Skin {
        Self::load(ctx, EMBEDDED).unwrap_or_else(|e| {
            log::error!("embedded skin: {e}");
            Self::fallback()
        })
    }

    /// Sin piezas: quien dibuja usa el respaldo plano.
    pub fn fallback() -> Skin {
        Skin {
            pieces: HashMap::new(),
            colors: SkinColors::from_theme(),
        }
    }

    pub fn from_data(ctx: &egui::Context, data: SkinData) -> Skin {
        let pieces = data
            .pieces
            .into_iter()
            .map(|(name, img)| {
                let size = [img.size[0] as usize, img.size[1] as usize];
                let image = egui::ColorImage::from_rgba_unmultiplied(size, &img.rgba);
                let texture = ctx.load_texture(
                    format!("skin:{name}"),
                    image,
                    egui::TextureOptions::NEAREST,
                );
                let piece = Piece {
                    texture,
                    size: img.size,
                    center: img.center,
                };
                (name, piece)
            })
            .collect();
        Skin {
            pieces,
            colors: SkinColors::with(&data.colors),
        }
    }

    /// La variante del estado o, si no está, la pieza base.
    pub fn piece(&self, name: &str, state: WidgetState) -> Option<&Piece> {
        let suffix = state.suffix();
        if !suffix.is_empty()
            && let Some(piece) = self.pieces.get(&format!("{name}{suffix}"))
        {
            return Some(piece);
        }
        self.pieces.get(name)
    }

    pub fn colors(&self) -> &SkinColors {
        &self.colors
    }
}

//! Recarga en vivo del skin (solo escritorio). Con `CHIMPSPRITE_SKIN=<ruta>` la app lee el skin de
//! ese archivo y lo vuelve a leer cuando cambia su fecha de modificación.

use std::path::PathBuf;
use std::time::SystemTime;

/// Variable de entorno con la ruta del skin a vigilar.
pub const SKIN_ENV: &str = "CHIMPSPRITE_SKIN";

/// Cada cuánto se mira la fecha del archivo, como mucho (segundos).
const INTERVAL: f64 = 1.0;

pub struct SkinWatcher {
    path: PathBuf,
    /// Fecha de la última lectura.
    modified: Option<SystemTime>,
    /// Última revisión (reloj de egui).
    checked: Option<f64>,
    /// Ya se avisó que no se puede leer (se avisa una vez hasta que vuelva a andar).
    warned: bool,
}

impl SkinWatcher {
    pub fn from_env() -> Option<Self> {
        std::env::var_os(SKIN_ENV).map(|p| Self::new(PathBuf::from(p)))
    }

    pub fn new(path: PathBuf) -> Self {
        Self {
            path,
            modified: None,
            checked: None,
            warned: false,
        }
    }

    /// Los bytes del archivo si cambió desde la última lectura. `now` es el reloj de egui (s).
    pub fn poll(&mut self, now: f64) -> Option<Vec<u8>> {
        if self.checked.is_some_and(|t| now - t < INTERVAL) {
            return None;
        }
        self.checked = Some(now);
        let modified = match std::fs::metadata(&self.path).and_then(|m| m.modified()) {
            Ok(m) => m,
            Err(e) => {
                self.warn(&e);
                return None;
            }
        };
        if self.modified == Some(modified) {
            return None;
        }
        match std::fs::read(&self.path) {
            Ok(bytes) => {
                self.modified = Some(modified);
                self.warned = false;
                Some(bytes)
            }
            Err(e) => {
                self.warn(&e);
                None
            }
        }
    }

    fn warn(&mut self, e: &std::io::Error) {
        if !self.warned {
            log::warn!("skin {}: {e}", self.path.display());
            self.warned = true;
        }
    }
}

//! Apariencia de View → Pixel UI: la fuente pixel, la escala entera de la UI, el estilo sin
//! redondeo y el skin. Apagado, todo queda con el tema de siempre.

use std::sync::Arc;

use eframe::egui::{
    self, CornerRadius, FontData, FontDefinitions, FontFamily, FontId, FontTweak, TextStyle,
};

use crate::skin::Skin;
use crate::theme;
use crate::view::ViewSettings;

/// Fuente pixel del autor del proyecto: grilla de 16 px por em, mayúsculas de 7 px.
const PIXEL_FONT: &[u8] = include_bytes!("../../../assets/ui/chimpsprite.ttf");
pub const PIXEL_FONT_NAME: &str = "chimpsprite";
/// A 16 puntos, un píxel de la grilla de la fuente mide un punto (un píxel del skin).
pub const PIXEL_FONT_SIZE: f32 = 16.0;

/// Fuentes de egui. Con `pixel`, la fuente pixel va primera en la proporcional, y las de egui
/// quedan detrás para los glifos que no tiene (`•`, `…`, `▸`). La monoespaciada no cambia.
pub fn font_definitions(pixel: bool) -> FontDefinitions {
    let mut fonts = FontDefinitions::default();
    if pixel {
        // Sin hinting: los contornos ya caen en la grilla y el hinting solo podría moverlos.
        let tweak = FontTweak {
            hinting: Some(false),
            ..Default::default()
        };
        fonts.font_data.insert(
            PIXEL_FONT_NAME.to_owned(),
            Arc::new(FontData::from_static(PIXEL_FONT).tweak(tweak)),
        );
        fonts
            .families
            .entry(FontFamily::Proportional)
            .or_default()
            .insert(0, PIXEL_FONT_NAME.to_owned());
    }
    fonts
}

/// El tema de siempre. Con `pixel`, además, la fuente pixel a 16 en los textos proporcionales y
/// nada redondeado (ventanas, menús y widgets).
pub fn apply_style(ctx: &egui::Context, pixel: bool) {
    theme::apply(ctx);
    let defaults = egui::Style::default().text_styles;
    ctx.all_styles_mut(|style| {
        style.text_styles = defaults.clone();
        if !pixel {
            return;
        }
        for text in [
            TextStyle::Small,
            TextStyle::Body,
            TextStyle::Button,
            TextStyle::Heading,
        ] {
            style
                .text_styles
                .insert(text, FontId::proportional(PIXEL_FONT_SIZE));
        }
        let visuals = &mut style.visuals;
        visuals.window_corner_radius = CornerRadius::ZERO;
        visuals.menu_corner_radius = CornerRadius::ZERO;
        for w in [
            &mut visuals.widgets.noninteractive,
            &mut visuals.widgets.inactive,
            &mut visuals.widgets.hovered,
            &mut visuals.widgets.active,
            &mut visuals.widgets.open,
        ] {
            w.corner_radius = CornerRadius::ZERO;
        }
    });
}

/// Pixel UI en la app: el skin y lo último aplicado.
pub struct PixelUi {
    /// Se lee la primera vez que se enciende.
    skin: Option<Skin>,
    /// Lo último aplicado: `(encendido, escala)`.
    applied: Option<(bool, u8)>,
    /// Recarga en vivo (`CHIMPSPRITE_SKIN`).
    #[cfg(not(target_arch = "wasm32"))]
    watcher: Option<crate::skin::watch::SkinWatcher>,
}

impl PixelUi {
    pub fn from_env() -> Self {
        Self {
            skin: None,
            applied: None,
            #[cfg(not(target_arch = "wasm32"))]
            watcher: crate::skin::watch::SkinWatcher::from_env(),
        }
    }

    /// El skin, solo con Pixel UI encendido.
    pub fn skin(&self) -> Option<&Skin> {
        if self.applied.is_some_and(|(on, _)| on) {
            self.skin.as_ref()
        } else {
            None
        }
    }

    /// Una vez por frame, antes de dibujar: aplica el interruptor y la escala si cambiaron, y
    /// mantiene `pixels_per_point` entero aunque cambie la escala del sistema.
    pub fn update(&mut self, ctx: &egui::Context, view: &ViewSettings) {
        let state = (view.pixel_ui, view.pixel_scale());
        if view.pixel_ui {
            self.load_skin(ctx);
            // No hace nada si ya es esa escala; egui la traduce a zoom = escala / la del sistema.
            ctx.set_pixels_per_point(state.1 as f32);
        }
        if self.applied == Some(state) {
            return;
        }
        let was_on = self.applied.is_some_and(|(on, _)| on);
        self.applied = Some(state);
        ctx.set_fonts(font_definitions(view.pixel_ui));
        apply_style(ctx, view.pixel_ui);
        // El Ctrl+/- de egui rompería la escala entera. En la web viene apagado (lo maneja el
        // navegador).
        ctx.options_mut(|o| {
            o.zoom_with_keyboard = !view.pixel_ui && !cfg!(target_arch = "wasm32");
        });
        if was_on && !view.pixel_ui {
            // Vuelve a la escala del sistema.
            ctx.set_zoom_factor(1.0);
        }
    }

    /// Lee el skin la primera vez. En escritorio, con `CHIMPSPRITE_SKIN`, lo vuelve a leer cuando
    /// cambia el archivo; si está roto, se queda el anterior y se avisa en el log.
    fn load_skin(&mut self, ctx: &egui::Context) {
        #[cfg(not(target_arch = "wasm32"))]
        if let Some(watcher) = &mut self.watcher {
            // Revisa el archivo aunque no haya eventos.
            ctx.request_repaint_after(std::time::Duration::from_secs(1));
            if let Some(bytes) = watcher.poll(ctx.input(|i| i.time)) {
                match Skin::load(ctx, &bytes) {
                    Ok(skin) => self.skin = Some(skin),
                    Err(e) => log::warn!("{e} (keeping the previous skin)"),
                }
            }
        }
        if self.skin.is_none() {
            self.skin = Some(Skin::embedded(ctx));
        }
    }
}

//! Piezas de la UI en pixel art dibujadas con el skin: diálogos y botones. Si el skin no trae una
//! pieza, se dibuja un respaldo plano con sus colores (fondo `panel`, borde `outline` de 1 px, sin
//! redondeo).

use eframe::egui::{
    self, Align2, Color32, Id, Rect, Response, Sense, Shape, Stroke, StrokeKind, TextStyle, Ui,
    Vec2, pos2, vec2,
};

use crate::skin::{IRect, Piece, Skin, WidgetState, nine_slice};

/// Marco de los diálogos: la ventana de barra rosa del mockup de "Unsaved changes".
const DIALOG_PIECE: &str = "window";
const BUTTON_PIECE: &str = "button";
/// Margen entre el área del centro del 9-slice y lo de adentro (contenido o texto).
const PADDING: f32 = 4.0;
/// Bordes del diálogo de respaldo (izquierda, arriba, derecha, abajo); arriba va la barra de
/// título.
const FALLBACK_DIALOG: [f32; 4] = [1.0, 13.0, 1.0, 1.0];
/// Bordes y tamaño mínimo del botón de respaldo (el alto del botón del mockup).
const FALLBACK_BUTTON: [f32; 4] = [1.0, 1.0, 1.0, 1.0];
const FALLBACK_BUTTON_SIZE: Vec2 = Vec2::new(32.0, 18.0);

/// Bordes del 9-slice de la pieza en puntos (izquierda, arriba, derecha, abajo). Con la escala
/// entera de Pixel UI, un punto es un píxel del skin.
fn borders(piece: &Piece) -> [f32; 4] {
    let [w, h] = piece.size;
    match piece.center {
        Some(c) => [
            c.x as f32,
            c.y as f32,
            (w - c.x - c.w) as f32,
            (h - c.y - c.h) as f32,
        ],
        None => [0.0; 4],
    }
}

/// Formas que dibujan `piece` estirada sobre `rect` (en 9-slice si tiene centro), alineadas a
/// píxeles de pantalla.
fn piece_shapes(piece: &Piece, rect: Rect, pixels_per_point: f32) -> Vec<Shape> {
    let ppp = pixels_per_point;
    let min = (rect.min.to_vec2() * ppp).round();
    let max = (rect.max.to_vec2() * ppp).round();
    let dest = IRect::new(
        min.x as i32,
        min.y as i32,
        (max.x - min.x) as i32,
        (max.y - min.y) as i32,
    );
    let [w, h] = piece.size;
    let parts: Vec<(IRect, IRect)> = match piece.center {
        Some(center) => {
            nine_slice(dest, piece.size, center, ppp.round().max(1.0) as u32).to_vec()
        }
        None => vec![(IRect::new(0, 0, w as i32, h as i32), dest)],
    };
    let (w, h) = (w as f32, h as f32);
    parts
        .into_iter()
        .filter(|(src, dst)| !src.is_empty() && !dst.is_empty())
        .map(|(src, dst)| {
            let screen = Rect::from_min_size(
                pos2(dst.x as f32 / ppp, dst.y as f32 / ppp),
                vec2(dst.w as f32 / ppp, dst.h as f32 / ppp),
            );
            let uv = Rect::from_min_size(
                pos2(src.x as f32 / w, src.y as f32 / h),
                vec2(src.w as f32 / w, src.h as f32 / h),
            );
            Shape::image(piece.texture.id(), screen, uv, Color32::WHITE)
        })
        .collect()
}

/// Respaldo plano: fondo `panel`, borde `outline` de 1 px y, si `title_bar > 0`, la barra de
/// título en `accent`.
fn flat_shapes(skin: &Skin, rect: Rect, title_bar: f32) -> Vec<Shape> {
    let colors = skin.colors();
    let mut shapes = vec![Shape::rect_filled(rect, 0.0, colors.panel)];
    if title_bar > 0.0 {
        let bar = Rect::from_min_size(rect.min, vec2(rect.width(), title_bar));
        shapes.push(Shape::rect_filled(bar, 0.0, colors.accent));
    }
    shapes.push(Shape::rect_stroke(
        rect,
        0.0,
        Stroke::new(1.0, colors.outline),
        StrokeKind::Inside,
    ));
    shapes
}

/// Diálogo fijo en el centro de la pantalla, con el marco del skin en 9-slice. El título va
/// centrado en la barra de arriba y el contenido en el área del centro, con 4 px de margen. El
/// texto de adentro usa `color.text`.
pub fn pixel_dialog<R>(
    ctx: &egui::Context,
    skin: &Skin,
    id: Id,
    title: &str,
    add_contents: impl FnOnce(&mut Ui) -> R,
) -> R {
    let piece = skin.piece(DIALOG_PIECE, WidgetState::Normal);
    let [left, top, right, bottom] = piece.map_or(FALLBACK_DIALOG, borders);
    let side = |v: f32| (v + PADDING).min(i8::MAX as f32) as i8;
    let margin = egui::Margin {
        left: side(left),
        right: side(right),
        top: side(top),
        bottom: side(bottom),
    };
    let text = skin.colors().text;
    egui::Area::new(id)
        .order(egui::Order::Foreground)
        .anchor(Align2::CENTER_CENTER, Vec2::ZERO)
        .show(ctx, |ui| {
            // El marco se pinta detrás, cuando ya se sabe el tamaño del contenido.
            let background = ui.painter().add(Shape::Noop);
            let font = TextStyle::Body.resolve(ui.style());
            let galley = ui.painter().layout_no_wrap(title.to_owned(), font, text);
            let inner = egui::Frame::NONE.inner_margin(margin).show(ui, |ui| {
                ui.visuals_mut().override_text_color = Some(text);
                ui.set_min_width(galley.size().x);
                add_contents(ui)
            });
            let rect = inner.response.rect;
            let mut shapes = match piece {
                Some(p) => piece_shapes(p, rect, ui.ctx().pixels_per_point()),
                None => flat_shapes(skin, rect, top),
            };
            let bar = Rect::from_min_size(rect.min, vec2(rect.width(), top));
            shapes.push(Shape::galley(
                bar.center() - galley.size() / 2.0,
                galley,
                text,
            ));
            ui.painter().set(background, Shape::Vec(shapes));
            inner.inner
        })
        .inner
}

/// Botón con `button` en reposo, `button.hover` con el puntero encima y `button.down` mientras
/// se presiona.
///
/// El ancho se ajusta al texto, con 4 px de margen a cada lado del área del centro, sin bajar
/// del tamaño de la pieza. Devuelve un `Response` normal: clic, foco y teclado (Enter o Espacio
/// con foco).
pub fn pixel_button(ui: &mut Ui, skin: &Skin, label: &str) -> Response {
    let colors = *skin.colors();
    let font = TextStyle::Button.resolve(ui.style());
    let galley = ui
        .painter()
        .layout_no_wrap(label.to_owned(), font, colors.text);
    let base = skin.piece(BUTTON_PIECE, WidgetState::Normal);
    let [left, top, right, bottom] = base.map_or(FALLBACK_BUTTON, borders);
    let min = base.map_or(FALLBACK_BUTTON_SIZE, |p| {
        vec2(p.size[0] as f32, p.size[1] as f32)
    });
    let width = (left + PADDING + galley.size().x + PADDING + right)
        .ceil()
        .max(min.x);
    let (rect, response) = ui.allocate_exact_size(vec2(width, min.y), Sense::click());
    let enabled = ui.is_enabled();
    response.widget_info(|| {
        egui::WidgetInfo::labeled(egui::WidgetType::Button, enabled, label)
    });
    if ui.is_rect_visible(rect) {
        let state = if response.is_pointer_button_down_on() {
            WidgetState::Down
        } else if response.hovered() {
            WidgetState::Hover
        } else {
            WidgetState::Normal
        };
        let painter = ui.painter();
        match skin.piece(BUTTON_PIECE, state) {
            Some(piece) => painter.extend(piece_shapes(piece, rect, ui.ctx().pixels_per_point())),
            None => painter.extend(flat_shapes(skin, rect, 0.0)),
        }
        let inner = Rect::from_min_max(rect.min + vec2(left, top), rect.max - vec2(right, bottom));
        painter.galley(inner.center() - galley.size() / 2.0, galley, colors.text);
        if response.has_focus() {
            painter.rect_stroke(
                rect.expand(1.0),
                0.0,
                Stroke::new(1.0, colors.accent),
                StrokeKind::Outside,
            );
        }
    }
    response
}
