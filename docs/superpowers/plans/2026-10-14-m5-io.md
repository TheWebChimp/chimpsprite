# M5 — Abrir, guardar y exportar — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Abrir y guardar `.aseprite`/`.ase`, formato nativo `.chimp` (varios artboards), exportar PNG / secuencia PNG / GIF / spritesheet + JSON / atlas de todos los artboards, importar PNG.

**Architecture:** Nuevo crate `cs-io` (sin egui, compila a wasm): `aseprite` (lector/escritor según la spec pública `ase-file-specs.md`), `chimp` (zip con un `.aseprite` por artboard + `manifest.json`), `export` (png, gif, sheet, atlas), `import` (png). La UI usa `rfd` para diálogos nativos y lleva control de cambios sin guardar.

**Tech Stack:** flate2 1.1 (zlib, backend miniz_oxide), zip 9 (`deflate`), png 0.18, gif 0.14, serde_json, rfd 0.17 (solo `cs-ui`).

## Global Constraints

- Ningún archivo corrupto provoca panic: errores tipados (`IoError`) con mensaje descriptivo.
- Lectura `.aseprite`: header, frames, capas (imagen/grupo; tilemap → capa vacía + aviso), cels tipo 0/1/2 (tipo 3 → aviso), paletas 0x2019/0x0004/0x0011, tags 0x2018 + color de user data, slices 0x2022 (+ su user data) preservados en bruto. Grayscale → RGBA + aviso. Los avisos vuelven en `LoadReport`.
- Escritura `.aseprite`: RGBA o indexado, perfil sRGB, paleta 0x2019, capas con flags (visible, editable = !locked), opacidad válida (flag 1 del header), blend (incl. `Other(n)`), cels comprimidos con zlib, cels vinculados como tipo 1 cuando comparten imagen, posición y opacidad con un cel anterior de la misma capa, tags con dirección/repeat y color en user data, slices preservados.
- Modelo: `AnimDirection::PingPongReverse`, `Tag::repeat`, `Sprite::extra_chunks` (serde default) para round-trip sin pérdida.
- `.chimp` v1: zip con `manifest.json` (`{"format":"chimp","version":1,"artboards":[{"id","name","position":[x,y],"file"}]}`) y `artboards/<id>.aseprite`.
- Guardar como `.aseprite` un documento con más de un artboard no está permitido: se pide guardar como `.chimp`.
- Atajos: Ctrl+N nuevo, Ctrl+O abrir, Ctrl+S guardar, Ctrl+Shift+S guardar como, Ctrl+E exportar.

---

### Task 1: `cs-io::aseprite` + ajustes de modelo
**Tests:** round-trip (RGBA e indexado; grupos; cels vinculados y con posición negativa; tags con color/dirección/repeat; duraciones; blend `Other`; capas ocultas/bloqueadas; slices preservados); punto fijo `read(write(read(write(s)))) == read(write(s))`; render idéntico frame a frame; property test con sprites aleatorios; errores ante magic inválido, truncado y zlib corrupto (sin panic); lectura de paleta vieja 0x0004.

### Task 2: `cs-io::chimp`
**Tests:** round-trip de un documento con varios artboards (nombres, posiciones, contenido); manifest inválido o artboard faltante → error.

### Task 3: Export / import
`export_png(sprite, frame, scale)`, `export_png_sequence`, `export_gif(sprite, range, scale)` (paleta global si caben ≤255 colores, si no cuantización por frame; transparencia; delays; loop infinito), `export_sheet(sprite, layout, scale, json_format, name)` → (png, json estilo Aseprite con `frameTags`), `export_atlas(doc, scale)` → (png, json); `import_png(bytes) -> Sprite`, `import_png_layer(sprite, bytes, frame) -> Command`.
**Tests:** dimensiones y píxeles de cada export; GIF decodificado con el crate `gif` tiene los frames y delays esperados; JSON con frames y tags correctos; import de PNG RGBA y de PNG paletizado.

### Task 4: UI
Menú File (New, Open…, Save, Save As…, Import PNG as Layer…, Export…, Quit), diálogo Export (formato, alcance, escala, layout, JSON), título con nombre y `•` si hay cambios, confirmación al descartar cambios (New/Open/cerrar ventana), ventana de error, avisos de carga.
