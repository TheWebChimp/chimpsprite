# Modelos 3D, parte 2B: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extrude, Subdivide (caras en 4), Merge y Delete sobre lo elegido, con teclas y botones.

**Architecture:** Operaciones puras en `cs-3d/src/topology.rs` (devuelven el modelo y la selección
nuevos); en `cs-ui`, comandos de editor con un paso de undo, el Extrude interactivo como un gesto de
teclado con vista previa, teclas y una fila de botones en la pestaña del objeto.

**Tech Stack:** Rust 2024, egui 0.36, el UI kit propio.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-11-03-3d-modeling-2b-design.md`.
- Caras de 3 o 4 vértices siempre; sin huecos (cada arista interior compartida por 2 caras).
- Un paso de undo por operación (Extrude + su movimiento = uno); cancelar no deja paso.
- Componentes del kit; textos en inglés ("Extrude", "Subdivide", "Merge", "Delete"); comentarios
  en español. Sin `git checkout -- …`/`restore`/`stash`/`reset --hard`/`clean`; solo
  `git add <archivos propios>`; LF; no tocar `.design/`. Toolchain de siempre, cargo a prioridad
  baja; fmt y clippy limpios; commits en español con
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
