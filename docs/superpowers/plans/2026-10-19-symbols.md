# Símbolos (instancias de artboards) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Poder colocar un artboard dentro de otro como instancia con su propia línea de tiempo
(modos Graphic y Movie clip de Adobe Animate), con keyframes de posición, flip y opacidad.

**Architecture:** Un nuevo tipo de capa, `LayerKind::Instance`, guarda un `InstanceTrack` de keys.
Antes de componer, `cs_render::materialize` convierte cada capa de instancia en una capa de imagen
con cels temporales (render recursivo del artboard fuente), así que el render, las máscaras, el
clip y los exports existentes funcionan sin cambios. Hay una sola primitiva nueva,
`Command::SetInstanceTrack`; los ciclos se rechazan en `DocCommand::OnArtboard`.

**Tech Stack:** Rust 2024, workspace con crates `cs-core`, `cs-render`, `cs-commands`, `cs-io`,
`cs-tools`, `cs-agent`, `cs-ui` (egui 0.36) y `apps/chimpsprite-mcp` (rmcp).

Spec: `docs/superpowers/specs/2026-10-19-symbols-design.md`

```rust
//! Instancias: un artboard colocado dentro de otro, con su propia línea de tiempo.

use serde::{Deserialize, Serialize};

use crate::{ArtboardId, Sprite};

/// Cómo avanza la línea de tiempo del símbolo.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum Timing {
    /// Sincronizado con los frames del padre (como los "Graphic" de Animate).
    Graphic { first_frame: usize, play: GraphicPlay },
    /// Corre por tiempo, con las duraciones del símbolo, en loop (como los "Movie clip").
    MovieClip { first_frame: usize },
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum GraphicPlay {
    Loop,
    /// Avanza y se queda en el último frame.
    Once,
    /// Siempre el mismo frame.
    Single,
}

/// Estado de una instancia desde un frame del padre.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct InstanceKey {
    pub frame: usize,
    /// `None` = la capa no muestra nada desde este frame.
    pub source: Option<ArtboardId>,
    /// Esquina superior izquierda del símbolo, en píxeles del padre.
    pub position: (i32, i32),
    pub flip_h: bool,
    pub flip_v: bool,
    pub opacity: u8,
    pub timing: Timing,
}

impl InstanceKey {
    /// Key en loop desde el primer frame, sin flip y opaca.
    pub fn new(frame: usize, source: ArtboardId, position: (i32, i32)) -> Self {
        Self {
            frame,
            source: Some(source),
            position,
            flip_h: false,
            flip_v: false,
            opacity: 255,
            timing: Timing::Graphic {
                first_frame: 0,
                play: GraphicPlay::Loop,
            },
        }
    }
}

/// Keys de una capa de instancia, ordenadas por frame; cada una vale hasta la siguiente.
#[derive(Clone, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct InstanceTrack {
    pub keys: Vec<InstanceKey>,
}

impl InstanceTrack {
    /// Key vigente en `frame` (la última que empieza en o antes de él).
    pub fn key_at(&self, frame: usize) -> Option<&InstanceKey> {
        self.keys.iter().rev().find(|k| k.frame <= frame)
    }

    /// Pone (o reemplaza) la key de su frame, manteniendo el orden.
    pub fn set_key(&mut self, key: InstanceKey) {
        match self.keys.binary_search_by_key(&key.frame, |k| k.frame) {
            Ok(i) => self.keys[i] = key,
            Err(i) => self.keys.insert(i, key),
        }
    }

    /// Quita la key que empieza en `frame`. `false` si no había.
    pub fn remove_key(&mut self, frame: usize) -> bool {
        let before = self.keys.len();
        self.keys.retain(|k| k.frame != frame);
        self.keys.len() != before
    }
}

/// Frame del símbolo `source` que se ve en el frame `frame` del padre, según `key`.
pub fn source_frame(key: &InstanceKey, parent: &Sprite, frame: usize, source: &Sprite) -> usize {
    let n = source.frames.len();
    if n == 0 {
        return 0;
    }
    let elapsed_frames = frame.saturating_sub(key.frame);
    match key.timing {
        Timing::Graphic { first_frame, play } => {
            let f0 = first_frame.min(n - 1);
            match play {
                GraphicPlay::Loop => (f0 + elapsed_frames) % n,
                GraphicPlay::Once => (f0 + elapsed_frames).min(n - 1),
                GraphicPlay::Single => f0,
            }
        }
        Timing::MovieClip { first_frame } => {
            let f0 = first_frame.min(n - 1);
            let total: u64 = source.frames.iter().map(|f| f.duration_ms as u64).sum();
            if total == 0 {
                return f0;
            }
            let end = frame.min(parent.frames.len());
            let start = key.frame.min(end);
            let elapsed: u64 = parent.frames[start..end]
                .iter()
                .map(|f| f.duration_ms as u64)
                .sum();
            let mut t = elapsed % total;
            let mut f = f0;
            // Termina: `total > 0`, así que alguna duración es mayor que lo que queda.
            loop {
                let duration = source.frames[f].duration_ms as u64;
                if t < duration {
                    return f;
                }
                t -= duration;
                f = (f + 1) % n;
            }
        }
    }
}
```

```rust
    /// Artboards que `id` instancia directamente (en cualquier key de cualquier capa).
    pub fn instance_sources(&self, id: ArtboardId) -> Vec<ArtboardId> {
        let Some(artboard) = self.artboard(id) else {
            return Vec::new();
        };
        let mut out: Vec<ArtboardId> = artboard
            .sprite
            .layers
            .iter()
            .filter_map(|l| l.instance.as_ref())
            .flat_map(|t| t.keys.iter().filter_map(|k| k.source))
            .collect();
        out.sort();
        out.dedup();
        out
    }

    /// ¿Instanciar `source` dentro de `host` haría que `host` se contenga a sí mismo?
    pub fn would_cycle(&self, host: ArtboardId, source: ArtboardId) -> bool {
        let mut stack = vec![source];
        let mut seen = std::collections::HashSet::new();
        while let Some(id) = stack.pop() {
            if id == host {
                return true;
            }
            if seen.insert(id) {
                stack.extend(self.instance_sources(id));
            }
        }
        false
    }

    /// Ninguna instancia de `id` lo contiene (directa o indirectamente).
    pub fn cycle_free(&self, id: ArtboardId) -> bool {
        self.instance_sources(id)
            .into_iter()
            .all(|s| !self.would_cycle(id, s))
    }
```

```rust
//! Instancias: antes de componer, cada capa de instancia se convierte en una capa de imagen con
//! el artboard fuente ya renderizado en su frame.

use std::borrow::Cow;
use std::ops::Range;
use std::sync::Arc;

use cs_core::{
    Cel, ColorMode, Document, Image, ImageId, InstanceKey, InstanceTrack, LayerKind, PixelValue,
    Rgba, Sprite, source_frame,
};

use crate::render_frame;

/// Profundidad máxima de instancias anidadas (defensa contra ciclos en datos corruptos).
const MAX_DEPTH: u32 = 16;

/// Copia del sprite donde las capas de instancia son capas de imagen con un cel en cada frame de
/// `frames` en que se ve algo. Sin capas de instancia devuelve el mismo sprite.
pub fn materialize<'a>(doc: &Document, sprite: &'a Sprite, frames: Range<usize>) -> Cow<'a, Sprite> {
    materialize_at(doc, sprite, frames, 0)
}

/// `materialize` de todos los frames, para formatos sin instancias. `None` si no hay.
pub fn bake_instances(doc: &Document, sprite: &Sprite) -> Option<Sprite> {
    match materialize(doc, sprite, 0..sprite.frames.len()) {
        Cow::Borrowed(_) => None,
        Cow::Owned(s) => Some(s),
    }
}

fn materialize_at<'a>(
    doc: &Document,
    sprite: &'a Sprite,
    frames: Range<usize>,
    depth: u32,
) -> Cow<'a, Sprite> {
    if !sprite.layers.iter().any(|l| l.kind == LayerKind::Instance) {
        return Cow::Borrowed(sprite);
    }
    let mut out = sprite.clone();
    let mut next = sprite.next_image_id().0;
    let can_draw = sprite.color_mode == ColorMode::Rgba && depth < MAX_DEPTH;
    for layer in &mut out.layers {
        if layer.kind != LayerKind::Instance {
            continue;
        }
        layer.kind = LayerKind::Image;
        let Some(track) = layer.instance.take() else {
            continue;
        };
        if !can_draw {
            continue;
        }
        for frame in frames.clone() {
            let Some((position, image)) = instance_image(doc, sprite, &track, frame, depth) else {
                continue;
            };
            let id = ImageId(next);
            next += 1;
            out.images.insert(id, Arc::new(image));
            let opacity = track.key_at(frame).map_or(255, |k| k.opacity);
            out.cels.insert(
                (layer.id, frame),
                Cel {
                    position,
                    opacity,
                    image: id,
                },
            );
        }
    }
    Cow::Owned(out)
}

/// Lo que muestra la instancia en `frame`: posición del cel e imagen recortada a lo opaco.
fn instance_image(
    doc: &Document,
    parent: &Sprite,
    track: &InstanceTrack,
    frame: usize,
    depth: u32,
) -> Option<((i32, i32), Image)> {
    let key: &InstanceKey = track.key_at(frame)?;
    let source = &doc.artboard(key.source?)?.sprite;
    let sf = source_frame(key, parent, frame, source);
    let inner = materialize_at(doc, source, sf..sf + 1, depth + 1);
    let pixels = render_frame(&inner, sf);
    let (w, h) = (source.width, source.height);
    let at = |x: u32, y: u32| -> Rgba {
        let sx = if key.flip_h { w - 1 - x } else { x };
        let sy = if key.flip_v { h - 1 - y } else { y };
        pixels[(sy * w + sx) as usize]
    };
    let (mut x0, mut y0, mut x1, mut y1) = (w, h, 0, 0);
    for y in 0..h {
        for x in 0..w {
            if at(x, y).a > 0 {
                (x0, y0, x1, y1) = (x0.min(x), y0.min(y), x1.max(x + 1), y1.max(y + 1));
            }
        }
    }
    if x0 >= x1 || y0 >= y1 {
        return None;
    }
    let mut image = Image::new(x1 - x0, y1 - y0, ColorMode::Rgba);
    for y in y0..y1 {
        for x in x0..x1 {
            image
                .set(x - x0, y - y0, PixelValue::Rgba(at(x, y)))
                .expect("in bounds and RGBA");
        }
    }
    let position = (key.position.0 + x0 as i32, key.position.1 + y0 as i32);
    Some((position, image))
}
```

```rust
/// Corre las keys de todas las capas de instancia por `f`; devuelve los comandos que las
/// restauran (si dos caen en el mismo frame gana la última).
fn remap_instances(doc: &mut Sprite, f: impl Fn(usize) -> usize) -> Vec<Command> {
    let mut inverse = Vec::new();
    for layer in &mut doc.layers {
        let Some(track) = layer.instance.as_mut() else {
            continue;
        };
        let old = std::mem::take(track);
        for key in &old.keys {
            track.set_key(InstanceKey {
                frame: f(key.frame),
                ..*key
            });
        }
        inverse.push(Command::SetInstanceTrack {
            layer: layer.id,
            track: old,
        });
    }
    inverse
}
```

```rust
/// Cambia con `f` la key vigente de `layer` en `frame`; si `frame` no es keyframe, la copia ahí
/// primero. `None` si no hay key vigente o nada cambia.
pub fn update_instance_key(
    sprite: &Sprite,
    layer: LayerId,
    frame: usize,
    f: impl FnOnce(&mut InstanceKey),
) -> Option<Command> {
    let track = sprite.layer(layer)?.instance.as_ref()?;
    let mut key = *track.key_at(frame)?;
    key.frame = frame;
    f(&mut key);
    let mut new = track.clone();
    new.set_key(key);
    (new != *track).then_some(Command::SetInstanceTrack { layer, track: new })
}

    }
    if track.keys.len() == 1 {
        return remove_layer_tree(sprite, layer);
    }
    let mut new = track.clone();
```

```rust
        let d = &self.doc(&p.doc)?.document;
        let host = target::artboard(d, p.artboard.as_ref())?;
        let source = target::artboard(d, Some(&p.source))?;
```

```rust
//! Instancias de artboards (símbolos) desde el editor y el panel.

use cs_commands::{Command, ops};
use cs_core::{ArtboardId, ColorMode, InstanceKey, LayerId};

use crate::editor::Editor;

impl Editor {
    /// Artboards que se pueden instanciar en el activo: no crean ciclos y el activo es RGBA.
    pub fn instance_candidates(&self) -> Vec<(ArtboardId, String)> {
        if self.sprite().color_mode != ColorMode::Rgba {
            return Vec::new();
        }
        self.document
            .artboards
            .iter()
            .filter(|a| !self.document.would_cycle(self.active, a.id))
            .map(|a| (a.id, a.name.clone()))
            .collect()
    }

    /// Nueva capa de instancia de `source` sobre la capa actual, centrada, con key en el frame actual.
    pub fn add_instance_layer(&mut self, source: ArtboardId) {
        let Some(src) = self.document.artboard(source) else {
            return;
        };
        let sprite = self.sprite();
        let position = (
            (sprite.width as i32 - src.sprite.width as i32) / 2,
            (sprite.height as i32 - src.sprite.height as i32) / 2,
        );
        let cmd = ops::new_instance_layer(
            sprite,
            Some(self.layer),
            self.frame,
            source,
            &src.name,
            position,
        );
        let id = match &cmd {
            Command::AddLayer { layer, .. } => layer.id,
            _ => unreachable!("new_instance_layer devuelve AddLayer"),
        };
        if self.execute(cmd) {
            self.layer = id;
        }
    }

    /// Key vigente de la capa actual en el frame actual (si es una capa de instancia).
    pub fn instance_key(&self) -> Option<InstanceKey> {
        let track = self.sprite().layer(self.layer)?.instance.as_ref()?;
        track.key_at(self.frame).copied()
    }

    pub fn is_instance_keyframe(&self, layer: LayerId, frame: usize) -> bool {
        self.sprite()
            .layer(layer)
            .and_then(|l| l.instance.as_ref())
            .is_some_and(|t| t.keys.iter().any(|k| k.frame == frame))
    }

    /// Cambia la key vigente de la capa actual; si el frame actual no es keyframe, crea uno.
    pub fn update_instance_key(&mut self, f: impl FnOnce(&mut InstanceKey)) {
        if let Some(cmd) = ops::update_instance_key(self.sprite(), self.layer, self.frame, f) {
            self.execute(cmd);
        }
    }

    /// Keyframe en `frame` copiando el vigente.
    pub fn insert_instance_key(&mut self, layer: LayerId, frame: usize) {
        if let Some(cmd) = ops::update_instance_key(self.sprite(), layer, frame, |_| {}) {
            self.execute(cmd);
        }
    }

    pub fn remove_instance_key(&mut self, layer: LayerId, frame: usize) {
        if let Some(cmd) = ops::remove_instance_key(self.sprite(), layer, frame) {
            self.execute(cmd);
        }
    }

    /// "Entrar al símbolo": activa el artboard fuente de la instancia actual.
    pub fn enter_instance(&mut self) -> bool {
        let Some(source) = self.instance_key().and_then(|k| k.source) else {
            return false;
        };
        if self.document.artboard(source).is_none() {
            return false;
        }
        self.activate(source);
        true
    }
}
```
